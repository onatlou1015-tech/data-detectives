What is ORDER BY?

ORDER BY sorts the rows of your result. You choose which column to sort by, and whether to go ascending (A→Z, small→large) or descending (Z→A, large→small).

The Basic Form

SQL 
SELECT column1, column2
FROM table
ORDER BY column ASC;   -- ascending (default)
SQL 
SELECT column1, column2
FROM table
ORDER BY column DESC;  -- descending
ASC is the default. If you don't write ASC or DESC, SQL assumes ASC.

Sorting by Name (Text)

Text columns sort alphabetically.

Students A → Z

SQL 
SELECT name, grade FROM students
ORDER BY name ASC;

Students Z → A

SQL 
SELECT name, grade FROM students
ORDER BY name DESC;

Sorting by Number

Number columns sort from smallest to largest (ASC) or largest to smallest (DESC).

Youngest to oldest students

SQL 
SELECT name, age FROM students
ORDER BY age ASC;

Oldest to youngest students

SQL 
SELECT name, age FROM students
ORDER BY age DESC;

Highest scores first

SQL 
SELECT student_id, score FROM scores
ORDER BY score DESC;

What is LIMIT?

LIMIT restricts how many rows are returned. It's often used with ORDER BY to get the "Top N" results.

Top 5 highest scores

SQL 
SELECT student_id, score FROM scores
ORDER BY score DESC
LIMIT 5;

Top 3 oldest students

SQL 
SELECT name, age FROM students
ORDER BY age DESC
LIMIT 3;
LIMIT without ORDER BY gives unpredictable results. Always sort first, then limit.

Sorting by Multiple Columns

You can sort by more than one column. The first column is the main sort; the second breaks ties.

Sort by grade, then by name

SQL 
SELECT name, grade, section FROM students
ORDER BY grade ASC, name ASC;

Sort by score high-to-low, then by student ID

SQL 
SELECT student_id, score FROM scores
ORDER BY score DESC, student_id ASC;
Think of multi-column sorting like sorting a deck of cards: first by suit, then by number.

ORDER BY with GROUP BY

You can sort grouped results. This is how you build leaderboards of groups.

Grades with the most students first

SQL 
SELECT grade, COUNT(*) AS total
FROM students
GROUP BY grade
ORDER BY total DESC;

Top 3 sections with the highest average age

SQL 
SELECT section, AVG(age) AS avg_age
FROM students
GROUP BY section
ORDER BY avg_age DESC
LIMIT 3;
Use AS to name your aggregate column so you can sort by it easily.

The Order of SQL Clauses

This is the order you must write your clauses. Remembering this will save you many mistakes.

SQL 
SELECT   columns
FROM     table
WHERE    condition
GROUP BY column
ORDER BY column ASC|DESC
LIMIT    number;
Order matters! WHERE always before GROUP BY. GROUP BY always before ORDER BY. ORDER BY always before LIMIT.

Real-Life Examples

📱 Social Media

Latest posts first:

SELECT * FROM posts ORDER BY date_posted DESC LIMIT 10;

🛒 Online Shopping

Top 5 best-selling products:

SELECT product_id, SUM(quantity) AS total FROM sales GROUP BY product_id ORDER BY total DESC LIMIT 5;

🏫 School Records

Top 10 students by average score:

SELECT student_id, AVG(score) AS avg_score FROM scores GROUP BY student_id ORDER BY avg_score DESC LIMIT 10;

🏥 Hospital System

Most recent patient visits:

SELECT * FROM visits ORDER BY visit_date DESC LIMIT 20;

🏦 Banking

Largest transactions today:

SELECT * FROM transactions WHERE date = CURDATE() ORDER BY amount DESC LIMIT 5;

Key Words to Remember

Term What It Means
ORDER BYSorts the rows of the result
ASCAscending order — A to Z, smallest to largest
DESCDescending order — Z to A, largest to smallest
LIMITRestricts how many rows are returned
Top NA common pattern: ORDER BY ... DESC LIMIT N
Multi-column sortSort by one column, then another to break ties
