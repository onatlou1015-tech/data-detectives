What is a Database?

A database is an organized collection of data that can be easily accessed, managed, and updated.

Think of it like a filing cabinet:

  • The cabinet is the database
  • The folders are the tables
  • The papers inside are the rows (records)
  • The fields on each paper are the columns
Without databases, every app you use would forget who you are the moment you close it.

Real-Life Examples

📱 Social Media

When you post on Facebook, your post is saved in a database.

Stored: your name, the post text, the time, likes, comments.

🛒 Online Shopping

When you order from Lazada or Shopee, your order is stored in a database.

Stored: your address, items ordered, price, delivery status.

🏫 School Records

Your grades, attendance, and student info are stored in a school database.

Stored: student ID, name, subjects, scores, absences.

🏥 Hospital Records

Patient information, appointments, and test results are stored in a database.

Stored: patient name, diagnosis, medicines, visit dates.

🏦 Banking

Every transaction you make is recorded in a secure database.

Stored: account number, amount, date, balance.

Key Words to Remember

Term What It Means
DatabaseAn organized collection of data
TableA collection of related data — like a spreadsheet
RowOne record in a table (one student, one order)
ColumnOne field in a table (name, age, grade)
FieldAnother word for a column
RecordAnother word for a row

Create Your First Table

Now it's your turn. Open phpMyAdmin in XAMPP and try the code below. This creates a table called students and adds 5 records.

Step 1: Create the table

SQL 
CREATE TABLE students (
  id INT AUTO_INCREMENT PRIMARY KEY,
  name VARCHAR(50),
  grade INT,
  section VARCHAR(10),
  age INT
);

Step 2: Add data

SQL 
INSERT INTO students (name, grade, section, age) VALUES
('Juan Dela Cruz', 10, 'A', 15),
('Maria Santos', 10, 'A', 16),
('Pedro Reyes', 10, 'B', 15),
('Ana Lopez', 10, 'B', 16),
('Jose Ramos', 10, 'A', 15);

Step 3: View your data

SQL 
SELECT * FROM students;
Copy each block into phpMyAdmin's SQL tab and click Go. You should see your 5 students appear in a table.
