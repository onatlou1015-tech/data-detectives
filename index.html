Data Detectives

Turning Information into Insight — A 7-Week SQL Journey

Welcome to the Unit

In this 7-week unit, you will learn how to collect, organize, and analyze data using SQL (Structured Query Language). Starting from simple tables, you will progress to answering real questions with queries and solving real-life problems with data.

By the end, you will design your own database and use SQL to find insights that add value to school or community services.

"Data is everywhere. The detective's job is to find the story inside it."
