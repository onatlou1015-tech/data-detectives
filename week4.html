Grouping Data (GROUP BY)

Comparing groups in data

Welcome Back!

Last week, you learned to summarize all the data with COUNT, AVG, and SUM. But what if you want to summarize by group?

For example: "How many students are in each grade?" or "What's the average age per section?" That's where GROUP BY comes in.

By the end of this lesson, you'll be able to break data into groups and compare them — a skill real analysts use every day.

What is GROUP BY?

GROUP BY groups rows that have the same value in a column. Then you can apply an aggregate function to each group.

Think of it like sorting your classmates into piles:

  • All Grade 10 students go in one pile
  • All Grade 11 students go in another pile
  • All Grade 12 students go in a third pile

Then you count how many are in each pile.

The Basic Form

SQL 
SELECT column, AGGREGATE(column)
FROM table
GROUP BY column;
Rule to remember: Every column in SELECT must either be in GROUP BY or inside an aggregate function.

COUNT with GROUP BY

Count how many rows are in each group.

Count students per grade

SQL 
SELECT grade, COUNT(*) FROM students
GROUP BY grade;

Count students per section

SQL 
SELECT section, COUNT(*) FROM students
GROUP BY section;

Count males and females

SQL 
SELECT gender, COUNT(*) FROM students
GROUP BY gender;

AVG with GROUP BY

Find the average value for each group.

Average age per grade

SQL 
SELECT grade, AVG(age) FROM students
GROUP BY grade;

Average score per subject

SQL 
SELECT subject_id, AVG(score) FROM scores
GROUP BY subject_id;

SUM with GROUP BY

Find the total value for each group.

Total quantity sold per item

SQL 
SELECT item_id, SUM(quantity) FROM canteen_sales
GROUP BY item_id;

Total score per student

SQL 
SELECT student_id, SUM(score) FROM scores
GROUP BY student_id;

GROUP BY with WHERE

You can filter rows before grouping them using WHERE.

Count females per grade (only females)

SQL 
SELECT grade, COUNT(*) FROM students
WHERE gender = 'F'
GROUP BY grade;

Average score per subject (only passing scores)

SQL 
SELECT subject_id, AVG(score) FROM scores
WHERE score >= 75
GROUP BY subject_id;
WHERE goes BEFORE GROUP BY. WHERE filters rows. GROUP BY organizes what's left.

Multiple Aggregates in One Query

You can combine several aggregates to get a full summary of each group.

Grade report with multiple aggregates

SQL 
SELECT grade,
       COUNT(*) AS total_students,
       AVG(age) AS avg_age,
       MIN(age) AS youngest,
       MAX(age) AS oldest
FROM students
GROUP BY grade;
Use AS to give your result columns friendly names — this makes reports much easier to read.

Real-Life Examples

📱 Social Media

How many posts does each user have?

SELECT user_id, COUNT(*) FROM posts GROUP BY user_id;

🛒 Online Shopping

What's the total sales per product category?

SELECT category, SUM(price * quantity) FROM sales GROUP BY category;

🏫 School Records

How many students per section?

SELECT section, COUNT(*) FROM students GROUP BY section;

🏥 Hospital System

Average temperature per ward?

SELECT ward, AVG(temperature) FROM patients GROUP BY ward;

🏦 Banking

Total deposits per branch?

SELECT branch, SUM(amount) FROM transactions WHERE type = 'Deposit' GROUP BY branch;

Key Words to Remember

Term What It Means
GROUP BYGroups rows with the same value in a column
AggregateA function that summarizes many rows (COUNT, AVG, SUM, etc.)
GroupA set of rows that share the same value
WHERE vs GROUP BYWHERE filters rows; GROUP BY organizes them
ASRenames a result column for readability
