Week 2

Retrieving Data (SELECT and WHERE)

How to ask questions from a database

Welcome Back!

Last week, you created your first database table and added records. Now it's time to ask questions from that data.

Every time you search for a friend on Facebook, filter products on Shopee, or check your grades online — a SELECT query is working behind the scenes.

This week, you'll learn how to retrieve exactly the data you need using two of the most important SQL commands: SELECT and WHERE.

Learning Outcomes

By the end of this week, you will be able to:

Higher Order Thinking Skills (HOTS)

ANALYZE Differentiate between retrieving all data (SELECT *) and retrieving specific data (SELECT column + WHERE) by comparing their results in real databases.
APPLY Use SELECT and WHERE to answer real-world questions — such as finding students in a specific grade, section, or age group.
EVALUATE Assess which query produces the most accurate and useful result for a given real-life scenario (e.g., "Who are the Grade 10 females in Section A?").

What is SELECT?

SELECT is the SQL command used to retrieve data from a database. It's how you ask a question.

The Basic Form

SQL 
SELECT column_name FROM table_name;

Retrieve Everything

Use the asterisk * to get all columns:

SQL 
SELECT * FROM students;

Retrieve Specific Columns

List only the columns you want:

SQL 
SELECT name, grade FROM students;
Fewer columns = faster query. Real apps only select the columns they need.

What is WHERE?

WHERE is the SQL keyword used to filter data. It's like a sieve — only rows that match your condition pass through.

Filter by one condition

SQL 
SELECT * FROM students
WHERE grade = 10;

Filter by text

SQL 
SELECT * FROM students
WHERE gender = 'F';

Combine two conditions with AND

SQL 
SELECT * FROM students
WHERE grade = 10 AND gender = 'F';

Use OR for either condition

SQL 
SELECT * FROM students
WHERE grade = 10 OR grade = 11;

Compare numbers

SQL 
SELECT * FROM students
WHERE age > 15;
Remember: Text values go inside single quotes 'like this'. Numbers do not.

Real-Life Examples

📱 Facebook Search

When you search a friend's name, Facebook runs something like:

SELECT * FROM users WHERE name = 'Juan Dela Cruz';

🛒 Shopee Filter

When you filter by price or category:

SELECT * FROM products WHERE price < 500 AND category = 'Electronics';

🏫 School Records

When your teacher views Grade 10 Section A:

SELECT * FROM students WHERE grade = 10 AND section = 'A';

🏥 Hospital System

When a nurse finds all patients with high fever:

SELECT * FROM patients WHERE temperature > 38;

🏦 Banking App

When you view transactions over ₱1000:

SELECT * FROM transactions WHERE amount > 1000;

Key Words to Remember

Term What It Means
SELECTRetrieves data from a table
FROMSpecifies which table to look in
WHEREFilters rows by a condition
ANDBoth conditions must be true
ORAt least one condition must be true
ConditionA test — like grade = 10 or age > 15
OperatorA symbol like =, >, <, >=, <=

Try It Yourself

Open phpMyAdmin and use the data_detectives database. Try each query below in the SQL tab.

Practice 1: See all students

SQL 
SELECT * FROM students;

Practice 2: Only Grade 10 students

SQL 
SELECT * FROM students
WHERE grade = 10;

Practice 3: Only females

SQL 
SELECT name, grade, section FROM students
WHERE gender = 'F';

Practice 4: Grade 10 females in Section A

SQL 
SELECT name FROM students
WHERE grade = 10 AND gender = 'F' AND section = 'A';

Practice 5: Students older than 15

SQL 
SELECT name, age FROM students
WHERE age > 15;

Practice 6: Grade 11 or Grade 12

SQL 
SELECT * FROM students
WHERE grade = 11 OR grade = 12;
Try changing the values and see how the results change. Experimentation is the fastest way to learn SQL.
