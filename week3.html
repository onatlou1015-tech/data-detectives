Summarizing Data (COUNT, AVG, SUM)

Turning raw data into insights

What are Aggregate Functions?

Aggregate functions are SQL tools that take many rows and return one summary value. They help you answer questions like:

  • How many students are in Grade 10?
  • What is the average score?
  • What is the total quantity sold?
  • Who has the highest score?

The Five Main Aggregates

Function What It Does Example
COUNT()Counts the number of rowsHow many students?
AVG()Calculates the averageAverage age?
SUM()Adds up all valuesTotal sales?
MIN()Finds the smallest valueYoungest student?
MAX()Finds the largest valueHighest score?
Aggregate functions return one row — a summary of all the data you asked about.

COUNT: How Many?

COUNT() counts how many rows match your query. It's the most common aggregate function.

Count all students

SQL 
SELECT COUNT(*) FROM students;

Count students in Grade 10

SQL 
SELECT COUNT(*) FROM students
WHERE grade = 10;

Count females in Section A

SQL 
SELECT COUNT(*) FROM students
WHERE gender = 'F' AND section = 'A';
COUNT(*) counts all rows. COUNT(column) counts only non-empty values in that column.

AVG: What's the Average?

AVG() calculates the average (mean) of a numeric column.

Average age of all students

SQL 
SELECT AVG(age) FROM students;

Average age of Grade 10 students

SQL 
SELECT AVG(age) FROM students
WHERE grade = 10;

Average score in a subject

SQL 
SELECT AVG(score) FROM scores
WHERE subject_id = 1;
AVG works only on numbers. Don't try to average names or text!

SUM: What's the Total?

SUM() adds up all values in a numeric column.

Total quantity of items sold

SQL 
SELECT SUM(quantity) FROM canteen_sales;

Total sales for one item

SQL 
SELECT SUM(quantity) FROM canteen_sales
WHERE item_id = 3;

Total score of one student

SQL 
SELECT SUM(score) FROM scores
WHERE student_id = 1;

MIN and MAX: Smallest and Largest

MIN() finds the smallest value. MAX() finds the largest.

Youngest and oldest student

SQL 
SELECT MIN(age) FROM students;
SELECT MAX(age) FROM students;

Highest and lowest score

SQL 
SELECT MAX(score) FROM scores;
SELECT MIN(score) FROM scores;
You can combine multiple aggregates in one query — like MIN(age), MAX(age) — to get several answers at once.

Real-Life Examples

📱 Social Media

How many likes did your last post get?

SELECT COUNT(*) FROM likes WHERE post_id = 42;

🛒 Online Shopping

What's the average price of items in your cart?

SELECT AVG(price) FROM cart_items WHERE cart_id = 7;

🏫 School Records

How many students are in Grade 10 Section A?

SELECT COUNT(*) FROM students WHERE grade = 10 AND section = 'A';

🏥 Hospital System

What's the average patient temperature today?

SELECT AVG(temperature) FROM patients WHERE visit_date = CURDATE();

🏦 Banking

What's the total amount of deposits made today?

SELECT SUM(amount) FROM transactions WHERE type = 'Deposit' AND date = CURDATE();
