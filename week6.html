Week 6

Connecting Tables (Simple JOIN)

How real databases link tables

Welcome Back!

So far, you've worked with one table at a time. But real databases use many tables that are linked together.

For example: students are in one table, subjects in another, and scores in a third. To answer "Who scored highest in Math?" you need to join the tables.

This week, you'll learn JOIN — one of the most powerful SQL skills. It's how real apps combine data from multiple sources.

Why Do We Split Data Into Multiple Tables?

Imagine putting everything in one table — students, subjects, scores, teachers. Every row would repeat the same names again and again.

Instead, we split data into related tables:

  • students — names, grades, sections
  • subjects — subject names, teachers
  • scores — links a student to a subject with a score
Fewer repetitions, fewer mistakes. That's why real databases use multiple linked tables.

Primary Keys and Foreign Keys

To link tables, each table has a primary key — a unique ID for each row. Other tables use that ID as a foreign key.

Term What It Means Example
Primary KeyUnique ID for each row in a tablestudents.id
Foreign KeyA column that points to a primary key in another tablescores.student_id

In our database:

  • scores.student_id points to students.id
  • scores.subject_id points to subjects.id
  • canteen_sales.item_id points to canteen_items.id

What is JOIN?

JOIN combines rows from two tables based on a related column. It's like matching two lists — you find rows that share the same ID.

The Basic Form

SQL 
SELECT column1, column2
FROM table1
JOIN table2 ON table1.id = table2.foreign_id;
How to read it: "Show me columns, from table1, joined with table2, where the ID matches."

Your First JOIN: Students and Scores

Let's combine students and scores to see each student's name next to their score.

SQL 
SELECT students.name, scores.score
FROM students
JOIN scores ON students.id = scores.student_id;

This returns every student's name paired with each of their scores.

Don't forget the ON clause. Without it, SQL doesn't know how the tables are connected.

JOIN with Three Tables

You can join more than two tables. Let's add subjects so we can see student names, subject names, and scores.

SQL 
SELECT students.name, subjects.name AS subject, scores.score
FROM scores
JOIN students ON scores.student_id = students.id
JOIN subjects ON scores.subject_id = subjects.id;

Now you can see: "Juan Dela Cruz — Mathematics — 88".

Use AS to rename columns when two tables have the same column name (like both having name).

JOIN with WHERE

Filter the joined result with WHERE just like before.

Find scores above 90

SQL 
SELECT students.name, scores.score
FROM students
JOIN scores ON students.id = scores.student_id
WHERE scores.score > 90;

Find Grade 10 students' Math scores

SQL 
SELECT students.name, scores.score
FROM students
JOIN scores ON students.id = scores.student_id
WHERE students.grade = 10 AND scores.subject_id = 1;

JOIN with GROUP BY and ORDER BY

Combine JOIN with the other tools you've learned to build powerful reports.

Average score per subject

SQL 
SELECT subjects.name AS subject, AVG(scores.score) AS avg_score
FROM scores
JOIN subjects ON scores.subject_id = subjects.id
GROUP BY subjects.name
ORDER BY avg_score DESC;

Top 5 students by total score

SQL 
SELECT students.name, SUM(scores.score) AS total
FROM students
JOIN scores ON students.id = scores.student_id
GROUP BY students.name
ORDER BY total DESC
LIMIT 5;
Notice how JOIN is followed by GROUP BY, then ORDER BY, then LIMIT — the same clause order you learned in Week 5.

Real-Life Examples

📱 Social Media

Show each user's name next to their post titles:

SELECT users.name, posts.title FROM posts JOIN users ON posts.user_id = users.id;

🛒 Online Shopping

Show each order's product name and quantity:

SELECT products.name, order_items.quantity FROM order_items JOIN products ON order_items.product_id = products.id;

🏫 School Records

Show each student's name with their subject scores:

SELECT students.name, subjects.name, scores.score FROM scores JOIN students ON scores.student_id = students.id JOIN subjects ON scores.subject_id = subjects.id;

🏥 Hospital System

Show each patient's name with their doctor's name:

SELECT patients.name, doctors.name FROM appointments JOIN patients ON appointments.patient_id = patients.id JOIN doctors ON appointments.doctor_id = doctors.id;

🏦 Banking

Show each customer's name with their account balance:

SELECT customers.name, accounts.balance FROM accounts JOIN customers ON accounts.customer_id = customers.id;
